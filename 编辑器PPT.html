编辑器使用说明
如果操作过程中遇到任何问题，可以联系 email：kaiyi.dai@loreal.com

1. 基本流程

  1. 先导入 HTML 文件，或点击“直接导入 HTML 代码”。
  2. 切换到“编辑模式”后，点击页面元素开始编辑。
  3. 完成修改后点击顶部“导出”保存结果。

2. 选择与导航

  1. W 外跳父节点，S 内跳子节点。
  2. A/D 左右同级切换。
  3. Esc 也可外跳父节点。
  4. Tab/Shift+Tab 同级前后切换。

3. 编辑操作

  1. 拖拽元素可改位置，右下角圆点可改尺寸。
  2. 右侧属性面板可调字体、颜色、边框、间距和变形。
  3. 双击文本元素可快速改字。

4. 快捷键

  1. Ctrl/Cmd+A 进入/退出纯浏览（隐藏全部编辑栏）。
  2. Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 重做。
  3. Ctrl/Cmd+C 复制选中元素。
  4. Ctrl/Cmd+D 删除选中元素。
  5. Enter 应用文本框内容（Shift+Enter 换行）。

5. Sync同步

  1. 先选中元素，点击左侧 加入同步栈。
  2. 再选其他任意元素，点击 加入同步栈 继续加入。
  3. 同步栈至少有 2 个元素时，拖拽、方向键、X/Y 输入会同步位移。
  4. 移除当前 可移出单个元素，清空同步栈 可整体重置。
